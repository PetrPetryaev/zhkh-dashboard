# ЖКУ — аналитика, кв. 370

Интерактивный дашборд коммунальных платежей за **декабрь 2024 — сентябрь 2026** (22 месяца).

🔗 **Открыть:** https://petrpetryaev.github.io/zhkh-dashboard/

> Страница закрыта от поисковиков (`noindex` + `robots.txt`) — в Google/Яндекс не попадёт. Доступна только по прямой ссылке.

## Что внутри

- Общая сумма платежей по месяцам (с трендом, мин/макс)
- Структура: квартплата и коммунальные услуги
- Из чего состоят коммунальные: отопление, электроэнергия, вода, водоотведение, ТКО
- Электроэнергия и отопление — объём и стоимость
- Холодная вода + водоотведение
- Изменение тарифов
- Детальная таблица помесячно с разницей месяц-к-месяцу

Один файл `index.html`, без сборки. Графики — [Chart.js](https://www.chartjs.org/) с CDN. Данные — из официальных квитанций ООО «А1».

## Как добавить новый месяц

В `index.html`, в блоке `<script>`: дописать название месяца в `MONTHS` и соответствующие значения в каждый массив `DATA` (в том же порядке). Инвариант: `kvartplata[i] + kommunal[i] === total[i]`.
